# 军师手册（回复建议模式的大脑）

这不是语录，是一套打法。我和我老师黄毛哥是一套理论，这里已经合成一份，用的时候不分谁讲的。
原话和出处在 `knowledge/`，答疑时引用；这份只管一件事：**看到她这条消息，下一步怎么走。**

---

## 一、底层逻辑：六条，所有判断都从这里推

1. **价值在于她对你有需求。** 她问你、找你、向你解释，你就在上位；你追、你解释、你讨好，就是在掉价。"追"这个动作本身就是降价。所以每条回复先问自己：这句发出去，是让她向我走，还是我向她走？
2. **兴趣看她做了什么，不看她说了什么。** 主动抛话题、秒回、发语音、追问你、向你解释、愿意来找你，才是真的。嘴上夸你、说想你，不算数。
3. **关系有台阶，跨级用招等于浪费。** 平衡（她对你有需求）→ 联系（能聊上、有共同点）→ 信任（她认可你、跟你交心）→ 情感（默认你是她的人）。没平衡就输出人设、讲道理，她听不进去；没信任就约，约出来也带不走。
4. **她缺什么，你就是什么。** 先判断她是哪类、平时身边是什么样的男人，再决定你演什么样的人。同一句话，对小绿茶是加分，对白富美是减分。
5. **主导权永远在你这。** 不解释（"只有弱者才要解释"）；她出难题就把问题抛回去；她给你下任务就把任务换回给她；让她问你、让她向你自证。
6. **你不缺她。** 手上有量，心态才稳；她冷了就放，她走了就换。心态一乱，前面五条全废。

## 二、每次回复前的读局（按顺序）

| # | 问自己 | 从哪看 | 结论决定什么 |
|---|---|---|---|
| 1 | **她现在有没有窗口？** | 最近几条：她回得多不多、快不快、有没有反问、有没有主动起话题 | 没窗口 → 基本不用往下想，放着 |
| 2 | **走到哪一级了？** | 打过电话没有、聊过两性没有、称呼变没变、见没见过、睡没睡过 | 决定这一步能用什么招、能不能约 |
| 3 | **她是哪类、缺什么？** | 朋友圈 / 主页 → 工作、性格、家庭 → 聊天风格（见第五节） | 决定人设和禁忌 |
| 4 | **她这条消息在干嘛？** | 这是第三节的入口：冷淡、示好、正常问、测试、拒绝、下任务、要关系、发难…… | 决定打法 |
| 5 | **你上一步有没有掉价？** | 你是不是比她发得多、在解释、在讨好、在追问 | 有就先止血：这一步收着发，甚至不发 |
| 6 | **用户自己还想不想要她？**（只在用户流露出腻了、想断时问） | 用户的话 | 不想要了 → 不管她发什么，都按"让它淡掉"处理：冷淡、往后推、她给台阶就顺着放，不摊牌也不冷暴力 |

判不出来的那一项，如果它会改变打法，就只问用户这一项；或者分情况各给一条回复。不改变打法的，不问。

## 三、打法：按"她这条消息在干嘛"出招

### ① 她冷淡：只回"嗯""哦""哈哈"，回得慢，不回
- **招**：不回不追、字数对等、朋友圈切入、三天定律（见 `招式表.md`）
- **判断**：这是没窗口，不是你哪句话说错了。她主动加的你也一样，主动加你不等于现在有窗口。她要么此刻没聊天的心境，要么觉得你暂时对她没用。
- **打法**：不追、不补话、不问"怎么了"。她不回你也不回。回复字数不超过她：她回"嗯"，你最多一两个字，或者干脆不回。
- **重新切入**：等她发朋友圈，从她的内容评论切回来；或者隔几天发一句不需要她接的轻话。刚加上三天还聊不开，就算了，去聊别人。
- **例外**：用户很想要、她又是慢热的那种（老实人、被骗过的），拉长线一两个月，发早、刷存在感。

### ② 她示好、主动、撩你
- **招**：短接往上推、甩电话、试探邀约、她约你就去（见 `招式表.md`）
- **判断**：窗口开了，这是往上推的时候，别只顾着享受。（例外：用户自己已经不想要她了，见读局第 6 问。）
- **打法**：短接一句往上推（"只是亲吗""怎么磨"）；她秒回、发语音、晚上九点到十一点 → "你旁边有人吗"，直接打电话；还没到可以约的级别，就随口提一句约，不迫切，让她习惯"以后会见"。
- **类型修正**：才几天就喊哥哥、关心你，多半是小绿茶的路数，接着但别上头；大绿茶主动约你，当场就接。

### ③ 她正常问你问题（在干嘛、做什么的、哪里人）
- **招**：说话说三分之一、职业升两级、制造冲突、第三方物 → 你和她（见 `招式表.md`）
- **打法**：话说三分之一，留个口子让她追问。她追问 = 有兴趣，你再展开。
  - "做什么的"→ 职业升两级、往她的行业靠，但只说一个词："传媒相关""帮公司做 IP 的"。
  - "哪里人"→ 只说到省。
  - "在干嘛"→ 给一个有点不合理、让她想问"为什么"的答案（"在开车，不方便说话"），她问了你再解答。她问来的才是价值，你主动说的是推销。
- **最后落回你和她**：她问"这边怎么样""你咋这么专业"，别答事实（NPC），答到你们俩身上，不点名——"跟这个人待一块舒服，搁哪都一样""不是专业，是因为我要见你"。

### ④ 她在测试你：带着答案问、给你定性、质问
- **招**：先顺应再声东击西、反问抛回、避重就轻（见 `招式表.md`）
- "你是不是经常这样加女生""你是不是渣男""你这条件追的人很多吧"——**先顺着认，再把话题带走**："对呀""如果每天都有现在这样的运气，我应该是会"。永远不急着反驳，一反驳就输了。
- "我们现在什么关系"——**不正面答，把问题抛回去**：没睡过 →"你觉得咱俩都这么相处了，你还问我什么关系？"；睡过 →"我们都躺在一起了，你觉得是什么关系？"
- 一段话里好几个点（"你身边异性很多吧、到底什么定位、昨天还躺一起"）——**挑最轻的那个词回**，别回最显眼的。

### ⑤ 她给你下任务、提要求
- **招**：任务奖励对调、夸张回应、生活号不聊工作（见 `招式表.md`）
- **有任务有奖励**（"你能不能来找我"）：把任务换回给她——"我腰病犯了开不了车，你来接我一趟，我带你去吃一家特别的店"。你定地方、定节奏。
- **只有任务没奖励**（"给我唱首歌"）：夸张回应，顺便测兴趣——"500 一首，办卡打折"。她讨价还价 = 有兴趣；她翻脸 = 本来就在逗你玩。
- **要东西、要转账**：你可以主动给，她不能主动要；送礼可以，转账不转。
- **借聊天让你干活**（带货、咨询、改简历）："要咨询的话额外预约时间，我生活号一般不聊工作。"

### ⑥ 她拒绝、推脱
- **招**：直接认、"那改日吧"、约人保底（见 `招式表.md`）
先看第二问"走到哪一级"，同一句"改天吧"处理完全不同：
- **刚加不久就推** → 窗口没开，放着。
- **已经暧昧、打过好几次电话还推（"改天""我社恐"）** → 不骂、不换下一个，反问："咱俩都打了好几个电话了，你跟我说社恐，你有把我当人看吗？难道我见的时候就不忐忑吗？" 别回"那周末？""你定个时间""那你哪天有空"，这是在追。
- **约好了临时不来、还酸你"你又不缺我一个"** → 不解释、不纠缠，直接认："不缺""别瞎猜了，给自己找这么多理由"，然后打电话把情绪拉回来。约好了被鸽是常态，所以永远同一天约两三个。
- **出发前说"12 点要撤"** →"嗯，那改日吧"；她问为啥，就把原因放在她身上（"还没开始就说撤，整得好像我影响你上班"），拉扯完马上打电话。
- **通用**：她拒绝的是你，不是那个活动。别一被推就改口"那咱不喝酒，去看电影"讨好她。

### ⑦ 她前后矛盾、嘴硬
- **招**：点破矛盾、对抗回去（见 `招式表.md`）
- **点破，不放过**：她先说酒量"先保密"（＝能喝），后面又说"酒量不好"——就拿这个点她，让她解释。你不点破，就是一直在退。
- **对抗型的**（你说东她偏说西）：跟她对抗——"你是真难伺候"。

### ⑧ 她倾诉、有情绪、发了丧气朋友圈
- **招**：故事钩子转电话、给"能解决"的感觉（见 `招式表.md`）
- **这是窗口**：直接问"遇到啥事了"。
- **先听，再讲你的故事**，最后才点评她（一上来就分析她会显得冒犯）。
- **情绪到位了转电话**："有空的话跟你讲个故事吧"→"旁边有人吗"→ 打。
- 她讲前任、讲家里的苦，当信息听，别当真、别站队。小绿茶哭穷提钱 → 给她"你能解决"的感觉，但不承诺给钱。

### ⑨ 她冷暴力、删你、说"算了"
- **招**：回 OK、朋友圈反追、一个"？"、冷淡让她断（见 `招式表.md`）
- **第一晚很火、第二天删你或说"权衡利弊你去找下一个"** → 这是在钓你。回"OK"，一个字不解释，字越少她想得越多。
- **态度骤降、长时间不理** → 不追问、不委屈求全。想拉回来，就先找出是哪一步出了问题（见面后冷了：是你线下和线上人设对不上，还是别的）；不想要了，就让它淡掉。
- **白富美那种冷**（几天回几个字）→ 不硬聊、不找人说情，从她朋友圈切入，管住自己的需求感；她哪天主动说"过去误会你了"，只回"？"，等她说完再淡淡一句"无所谓了，从小到大一直被人误会，都习惯了"。

### ⑩ 她夸自己、立人设
- **招**：暗示不直说（见 `招式表.md`）
- "我长得像嫩模""我又有趣"——要么天真要么自卑，别接她的人设；想让她多发照片就暗示："你朋友圈发的都太保守了。"
- "我不拧巴""我好久没跟男生聊天了"——反着听，看她做什么。

## 四、聊天 SOP：从加上到见面

**总规则：没到那一步，就做这一步的事。** 她出招时的应对（废测、问关系、删你、矛盾……）随时可能用，见 `招式表.md` 最后一节。 每一步有一个目标，看到"过关信号"才往下走；用户急着约、急着聊两性，先告诉他卡在哪一步。整个过程短择一般几天，拉长线的一两个月；但**任何一步三天没进展、她又没窗口，就别耗了，换人**。

### 第 0 步：加她之前——展示面和朋友圈
- **用的招**：朋友圈三样、预制朋友圈、车钥匙摆放（名字、做法、案例见 `招式表.md`）
- **目标**：让她来加你，加上之后一翻朋友圈就想跟你聊。
- **做什么**：展示面只吃同城流量；朋友圈三样——长相、生活爱好（吃的要精致）、价值观；置顶放最能代表你的；每周发一两条"给女生看的"预制朋友圈，让沉在列表里的人还记得你。
- **常见错误**：只发帅照不给话题；晒车晒钱（小绿茶怕、白富美嫌；大绿茶例外，可以刻意但不太显眼地展示）；发死板的"知识分子"内容。

### 第 1 步：刚加上——破冰，同时看她是谁
- **用的招**：发就行、朋友圈切入、开场带人设、不回不追、三天定律（名字、做法、案例见 `招式表.md`）
- **目标**：开个头，判断她是哪类、现在有没有窗口。
- **做什么**：开场没技巧，发就行；最快的是先在她朋友圈评论、回两三条再私聊；开场带一点人设（"这会还在加班"）等她问你。同时翻她朋友圈判类型。
- **过关信号**：她反问你、追问你、主动起话题。
- **没过关**：只回 hi / OK、短回 → 放着，等她朋友圈再切；三天还聊不开就换。
- **常见错误**：硬憋高级开场白；她不回就连发；问"怎么不回我"。

### 第 2 步：建立平衡——让她对你有需求
- **用的招**：说话说三分之一、制造冲突、字数对等、我在忙（名字、做法、案例见 `招式表.md`）
- **目标**：两个人价值差不多对等，她开始想从你这得到点什么（好奇、被逗乐、被认可）。这是下限，**没平衡之前什么技巧都没用**。
- **做什么**：话说三分之一，留口子；给有点不合理的回答让她追问；回复字数不超过她；她问你的事别讲太细；别热情过头、别追着发。
- **过关信号**：她开始问你问题、主动回你、回应你朋友圈的评论。
- **常见错误**：一上来就大段分享自己、狂夸她、秒回秒到她也觉得你闲。

### 第 3 步：建立联系——让她愿意跟你聊、觉得你不一样
- **用的招**：立差异感、职业升两级、第三方物 → 你和她、聊天公式、抛故事、双线程、抓关键词、发早、一句话多层意思、推拉、夸张回应、任务奖励对调、车轱辘话 + 故事（名字、做法、案例见 `招式表.md`）
- **目标**：能聊上、有共同点，你在她那里跟别的男生不一样。
- **做什么**：
  - **立差异感**：职业 + 反着来的作息 + 自律，做成一个她想探索的 IP（见第六节人设）。
  - **聊天公式**：第三方物（她发的东西、天气、下班）→ 第三方人（你的朋友、同事）→ 你和她；任何话题最后落回你们俩，不点名。
  - **抛故事**：先发两行概括，她想听再展开（见第六节）。
  - 想养习惯就固定时间发"早"。
  - 已经有平衡了，可以开始推拉（"我发现你跟刚认识的时候不太一样了"）。
- **过关信号**："你怎么这么懂""真的吗""不是吧"；她主动分享日常。
- **常见错误**：天天聊"吃了吗、在干嘛"这种客套话（聊多了就成朋友了）；查户口式提问。
- **类型差异**：老实人用双线程（信息互换 + 调情交织），话题多、能扯；小绿茶言简意赅、别开玩笑、别调情；大绿茶只聊当下、要快。

### 第 4 步：建立信任——让她认可你、跟你交心
- **用的招**：大方故事传人设、带她参与你的人生、情感过山车、让她自证、试探邀约、给"能解决"的感觉、生活号不聊工作（名字、做法、案例见 `招式表.md`）
- **目标**：她认可你这个人，愿意跟你讲她自己的事。
- **做什么**：讲你的故事、说你的三观，再问她的；顺着聊到"你喜欢跟什么样的人交朋友 → 喜欢什么样的男生 → 上一段恋爱 → 为什么分手"；她倾诉时先听、再讲你的、最后点评她；随口提一句约，不等她答复（试探邀约，老实人尤其要多做几次）。
- **过关信号**：她向你解释、自证；秒回、回得多、发语音；跟你讲家里、讲前任。
- **常见错误**：她讲家里苦就急着说"我帮你"（小绿茶的坑）；还没信任就正式约。

### 第 5 步：打电话——把关系拉一大截
- **用的招**：甩电话、故事钩子转电话（名字、做法、案例见 `招式表.md`）
- **目标**：用语音把关系往前推，"十分钟语音大于一百句文字"；打过一次电话，她就会把你放得比别的男生高。
- **什么时候打**：她秒回、回得多、发语音，晚上九点到十一点，"你旁边有人吗"→ 没人就直接打。她倾诉完，用"有空跟你讲个故事吧"做钩子转电话。
- **电话里做什么**：夸她声音、问她喜欢男生哪里、聊她朋友圈某张照片、讲故事、慢慢聊到两性；结尾可以模糊邀约（"周末组个局，你也带个闺蜜"）。
- **常见错误**：一直打字不敢打电话；打电话查户口。

### 第 6 步：暧昧——聊到两性
- **用的招**：第三方切两性、万能话术、短接往上推、暗示不直说、老实人聊性话术（名字、做法、案例见 `招式表.md`）
- **目标**：关系跟别人不一样了，"只有聊到两性，你们俩之间的关系才会跟别人不一样"。
- **前提**：前面熟悉感、信任感够了（看她回你的次数和话术）。"铺垫没到位就是开黄腔，铺垫好了叫调情。"
- **做什么**：不单刀直入，从第三方切——她的照片、穿搭、高跟鞋、她的工作应酬、一个出轨故事；她撩你就短接一句往上推；想让她发照片就暗示（"你朋友圈发的都太保守了"）；尽量在电话里聊，打字她有思考空间。
- **过关信号**：称呼变了，默认你是她的人；她接你的话、甚至主动撩。
- **类型差异**：老实人有专门的话术（"之前遇到的人都很主动，对这种人已经很恶心了，跟你聊天很开心"）；小绿茶别过早调情。

### 第 7 步：邀约
- **用的招**：速约给理由、话题邀约、让她来你这、模糊邀约 / 二对二、约人保底、她约你就去（名字、做法、案例见 `招式表.md`）
- **前提**：有情感连接了（称呼变了、暧昧了）。没到就约，"约七八次败六七次"，约出来也带不走。
- **做什么**：
  - 速约要给一个"为什么是今晚"的理由（"刚好在那边把客户送走"）；拉长线三四天后约就不用解释。
  - 用聊过的话题约（聊过电影就约电影，聊过喝酒就约喝酒）。
  - 让她来你这边：愿意晚上十点半以后出来、愿意坐车来找你，就是有戏。
  - 电话里约的，最好打完就见，隔几个小时就不稳。
  - 同一天约两三个保底。
- **她推了怎么办**：刚加就推 → 放着；暧昧了还推 → 反问；她拒绝的是你不是活动，别马上换活动讨好（见第三节⑥）。
- **类型差异**：大绿茶有兴趣立刻约、她约你就去；老实人别急，多试探几次再正式约。

### 第 8 步：见面前
- **用的招**：铺梗 + 指定穿搭、"那改日吧"、直接认（名字、做法、案例见 `招式表.md`）
- **目标**：保证她真来，见面不尬。
- **做什么**：先铺一个见面能接上的梗、指定她的穿搭；她出发前说"12 点要撤"就"那改日吧"再拉扯，拉完马上打电话；临时被鸽就直接认、不解释，然后打电话。
- 线下部分（地点、开场、喝酒、推进）见 `knowledge/05`。

### 第 9 步：见面后
- **用的招**：趁热打铁、几个字维护（名字、做法、案例见 `招式表.md`）
- **做什么**：感觉好就趁热打铁，第二天就约；维护期几个字就够（"晚安""搭配了哪套"）。
- **她冷了**：先判断还想不想要。想要 → 找出是哪一步对不上（线上线下人设不一致？）再改；不想要 → 让它淡掉。别哭、别发长消息、别分享日常求回应。
- **她第二天说"有喜欢的人了"**：你线下没达到她的预期，不纠缠。

## 五、类型速配：她缺什么、你演什么、什么不能碰

|---|---|---|---|---|---|
| **小绿茶**（软件上七八成） | 身材照 + 吐槽式文字、类心灵鸡汤文案；家里要钱；很会聊、几天喊哥哥、张口钱 | 稳：情绪稳、经济稳，而且她能"拿得住你" | 沉稳、愿意为对象花钱、包容她的小脾气 | 用一个大方付出的故事（比如初恋）传人设；言简意赅，抓她话里的关键词回；断断续续磨 | 开玩笑扯淡、聊情话、过早调情、晒车晒钱、AA；愧疚感对她没用 |

## 六、立人设和讲故事：你的两件武器

**人设是你在她心里是谁，故事是把人设送进她心里的方式。** 人设定了你的价值和差异感；故事让她自己得出"他是这样的人"，而不是听你说。黄毛哥的话："人更愿意相信的是他自己得出的结论。"

### 1. 人设

**作用**
- **抬价值**：职业、作息、生活方式，让她觉得你在上位、有她需要的东西（大绿茶要阶级，小绿茶要稳，白富美要精神层次）。
- **立差异感**：聊日常一定会断，你得是个"她想探索的 IP"，要么你说的戳中她，要么她主动来问你。
- **给她追问的口子**：人设里留一个不合理、不常见的点，她问了，价值就是她自己问出来的。

**什么时候立**
- **从第一句就开始**，但不说破：开场带一句"这会还在加班""刚把客户送走"，让她自己问你做什么。
- **她问了才给，只给三分之一**："传媒相关""帮公司做 IP 的"，她追问再多说。主动讲自己是推销，被问到才讲是价值。
- **主页、朋友圈先替你立**：她加你一定会翻朋友圈（长相、生活、价值观三样，置顶最重要）。
- **立成之后要守住一致性**：线下见面、消费、说话都要对得上，对不上她就冷了。

**怎么立**
- **半真半假**：真实职业往上升两级，最好落在她的行业上（她做自媒体 → 你"帮人做 IP"；她是医生 → "家里开诊所的"）；不懂就先问 AI 补点行业知识。纯假的线下会露馅。
- **差异感三件套**：职业 + 反着来的作息（周末忙、工作日闲）+ 自律（健身、吃得干净）。
- **侧面立，不直说**："我助理前几天被绿了"——没说我有助理，是故事需要才带出来。直接说"我是好人、我很专一、我三观正"是最蠢的。
- **按类型调**：小绿茶 → 沉稳、愿意为对象花钱、包容她，但别显得特别有钱；大绿茶 → 例外，可以直接植入硬价值（"我爸当官，我妈经商"），配合制造冲突让她追问；白富美 → 不装不吹，她能听出刻意，你为什么这么成熟这种事留到以后用故事讲；老实人 → 有趣、靠谱，长相谈吐声音对得上就够。

### 2. 讲故事

**作用**
1. **传人设**：故事里你怎么对人，她就认定你是什么人（为前任改专业、攒钱供她 → 她认定"他对女朋友会无条件好"）。
2. **侧面输出三观，再引出她的**：讲完说出你的看法，问她怎么看，她就开始讲她自己的。
3. **把话题自然带到两性**：讲两个人之间的事（出轨、被绿、捉奸），讲完聊看法，就到了两性，比直接问"谈过几个"自然，也显得你目的性不强。
4. **当钩子和转场**：她追问"后来呢"——线上转电话（"旁边有人吗"），线下换地方（"这边吵，换个地方聊"）。
5. **解释你身上让她起疑的地方**：她觉得你太成熟、太会来事，就讲一个小时候的故事把它解释了，而不是自己辩解。
6. **埋第三方人**：故事里的朋友、同事、店员，后面可以拿来聊"你喜欢什么样的人"。

**什么时候讲**
- **平衡感建立之后**（她会接话、会追问）。没平衡时讲故事，她只觉得你啰嗦。
- **联系 → 信任这一段是故事的主场**：冷场、没话题、聊日常聊不动的时候。
- **她倾诉之后**：先听完，再讲你的故事铺垫，最后才点评她。
- **她问三观大题**（"什么样的相处最好"）：先一段车轱辘话，马上接一个具体故事。晚上、喝酒时可以，下午讲会显得油。
- **想往两性走之前**：讲一个两个人之间的故事。
- **不讲的时候**：她没窗口时不讲；对大绿茶不讲长故事、初恋故事（她要的是现场看到的硬价值）。

**怎么讲**
1. **先发两行概括，测她想不想听**："真没想到，我们公司那几个人都咋打起来了"。她追问、发好几条甚至发语音，再展开；没兴趣就拉倒。
2. **固定开头**："这件事一直困扰我很久"，带一点正式感。
3. **带具体时间和标志性的东西**：哪一年、送的哪款包、在哪条街，故事才真。
4. **故事里你的立场，就是你要立的人设**：很爱前任、愿意付出、专一、被伤过但不怨。
5. **要够离谱、够八卦**："如果它不够离谱，那就不是八卦了"；八卦比讲知识强太多。
6. **讲完说三观，再把话题抛给她**："这事你怎么看""你遇到会怎么办"。
7. **讲到她追问就收住**，转电话或换场。

**备几个**：至少两三个现成的——成长故事、身边人的八卦、被绿 / 出轨、为前任付出。没有就改编朋友的事、看故事会、让豆包编，结合你自己的行业讲成自己的。

**按类型讲**
- **小绿茶**：讲"大方付出"的故事，比如初恋，让她自己得出你会对女朋友好、愿意花钱。
- **白富美**：带她参与你的人生——在普通地方（一个路边摊、一座桥）讲跟这里有关的你的重要节点，"带她吃的不是一顿饭，是我的回忆"。
- **老实人**：话题多、能扯就行，轻松的故事、扯犊子都可以。
- **大绿茶**：基本不讲故事，用现场的硬价值和制造冲突代替。
- **年纪小、需要人带的**：可以直接输出三观；年纪大一点的别这么干。

### 3. 不要
- 直说自己的人设（"我这个人很好的"）。
- 炫富：车钥匙摆桌上、晒车晒房（大绿茶那种"刻意但不太显眼"的展示是例外）。
- 立一个线下交付不了的身份。
- 故事里的第三方人跟她一模一样（像她三分之二就够，太像就假）。
- 用狠故事立人设（比如打过女人）——按边界表，换成"我分手很干脆，作的我直接走"。

## 七、话术怎么写

- **短、分条、口语**，一条一般不超过 15 个字；跟女生聊天不带粗口。
- **字数不超过她**：她一个字，你别一段话。
- **不解释、不道歉、不讲道理**；需要说明的，用故事、用第三方人带出来。
- **留口子**：一句话里给她一个能追问的点，最好不止一个。
- **不点名的暧昧**：说"跟这个人待一块舒服"，不说"我喜欢你"。
- 每条回复都能回答：为什么这句只适合这个局面，换个场景就不能用？答不上来就是在套模板。

## 八、红线（任何类型、任何阶段都不变）

- 让她多喝、喝醉、借她喝多推进；她推开、说不要之后还继续；她要走拦着不让走；用狠故事吓唬她——这些按 `SKILL.md` 边界表处理，不教。她说怕喝多，就不劝酒。
- 她未成年：不聊。
- 用户本人有轻生念头：先劝他找专业帮助，不谈技巧。
