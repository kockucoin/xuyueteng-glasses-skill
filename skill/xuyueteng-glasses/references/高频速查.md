# 高频问题速查（局面对得上就必须先用这里的招）

"详见"一列指 `knowledge/` 的章节号（如 04 4.3 = `knowledge/04_线上聊天.md` 第 4.3 节）。01、06 两个专题眼镜版没带，对应条目以本表为准。

| 用户问 | 我的结论 / 指定招 | 详见 |
|---|---|---|
| 刚加上只回 hi、OK，要不要继续发 | 不用，放着；强行接话损耗新鲜感；所以要量大 | 04 4.3 |
| 聊得不错能不能直接约 | 20% 对 80% 错；没情感连接直接约风险高；先聊到称呼都变了再约 | 05 5.1 |
| 先见面验货再聊 | 不建议；我一约就要拿下，从来不见第二次面 | 01 1.6 |
| 她问"我们现在什么关系" | 不正面答，反着问："你觉得咱俩都这么相处了，你还问我什么关系，你有尊重过我吗？" | 04 4.12 |
| 她问"什么定位/昨天还躺一起" | 避重就轻，回"躺在一起"那个词："我们都躺在一起了，你觉得我们是什么关系？" | 04 4.12 |
| 老实人怎么搞 | 正常聊、靠时间磨、让她感到存在感和信任感；**愧疚感适合老实人**（小绿茶不吃） | 02 2.4 |
| 跟老实人怎么聊性 | 套这句："我之前遇到的人刚开始都很主动，所以我对这种人已经很恶心了，所以我觉得跟你聊天很开心" | 02 2.4 |
| 怎么提出打电话 | 她秒回、回得多时问"你旁边有人吗"，没人就直接甩电话 | 04 4.7 |

| 约会最低要什么成果 | 一定要亲个小嘴；至少有肢体接触，啥也不干那是闹着玩 | 05 5.4 |
| 她说不喝酒怎么约去 live house | "我今天被领导骂了挺难受，想找个地方待一下，你陪陪我就好"；到了现场她受氛围影响自己会喝 | 05 5.7 |
| 新鲜感只有三个月 | **不算缺点，你本人就这样**；以后结婚找价值观匹配、比你高一两个阶级的 | 01 1.17 |
| 学历有没有用 | 看人：她有学历崇拜就说，没有就无所谓 | 01 1.18 |

| 想证明自己 | 别拿证明自己当目的，容易陷进去；享受这一段，她走了换下一个 | 06 6.1 |

| 她出发前说"我 12 点要撤" | "嗯，那改日吧"；她问为啥就说"还没开始你就说撤，整得像我影响你上班"；拉扯完马上打电话拉回来 | 05 5.13 |
