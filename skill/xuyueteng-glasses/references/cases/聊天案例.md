## 案例 2｜老实人：以进为退 + 愧疚感 → 她深夜自己坐地铁来
**女生 B**：23 岁，金融行业，牵手加的。腾判断为老实人（以前是女同、有点厌男，没怎么跟男生亲密接触过）。
**出处**：3-4 [18:01]–[27:29]

**第一段：她夸他，他不当回事**
```
她：你比我还辛苦 / 难怪年薪高
腾：六点上班 / 督促一下开个会差不多
她：[语音]（哎，你长得帅就算了，工作还努力，工作努力就算了，还有生活）
她：看来你很受欢迎了 / 那你本人啥样的呢
```
→ 腾："她夸我声音、夸我帅，我都不放心上……当屁话放了就好了，该咋说还是以自己的框架应对。"

**第二段：约她，她找理由推**
```
她：今晚不行 我姐妹在
腾：你姐妹在 / 那我过去也多此一举啊
腾：[语音]（我去不去，你都给个声吧）
她：改天吧 才到家 太累了 / 班味太重了
（隔了将近 3 小时）
腾：行 / 下次不提前请假了
她：谁请假了
```
→ 腾为什么隔三小时：他前面铺垫过自己上晚班，几小时不回是合理的；"下次不提前请假了"是让她知道**他为这次见面付出了**。

**第三段：加深愧疚，拒绝补偿**
```
她：抱歉了 / 确实没休息好 发现还长痘了 / 就想算了 / 我昨天晚上两点睡的 / 中午没午休
腾：我跟领导说今天见面很重要 / 才放我走的 / 扣点钱而已 没事
腾：高铁票作废了 / 重新买了张
她：难评
腾：好像 没把我话当回事
她：要不明天 / 补偿你 请你吃饭
腾：别 / 别用补偿这个词 / 我自己问题我负责
她：嗯嗯 / 早点休息吧 / 我快死了 / 感觉 / 晚安
```
→ 腾："如果我这时候立马答应'OK 明天去哪见面'，她心里就默认请吃饭把这事代偿了，后面就延续不下去了。"

**第四段：第二天他只说一句**
```
腾：今天晚上我OK
她：几点 / 我九点之后才有空
```
→ 结果：她陪姐妹逛了一整天，晚上 11 点多从白云坐一个多小时地铁过来。"说明我前面说的是起作用的。"

**可迁移的招**
- 愧疚感**只对老实人用**，小绿茶不吃这套
- 她推的时候不追问、不讨好，隔一段时间用一句话让她知道你的付出
- 她要"补偿"时拒绝，别让一顿饭把愧疚抵消掉
- 第二天只给一句确定的话，不解释

## 案例 3｜精神小妹·对抗型：她嘴硬，你也对抗
**女生 C**：23 岁，电商主播，牵手加的。腾判断为精神小妹，对抗型人格，聊暧昧聊不来。
**出处**：3-2 [05:51]–[08:14]

```
她：我最讨厌恐怖片了
腾：[语音]（你这真真难伺候啊）
腾：[语音]（嗯，看电影就真的好像是真的是为了看电影似的）
她：不然呢 / 看好看的电影行 / 恐怖片我本来就害怕 / 等下颜面尽失
腾：处成兄弟了
她：所以你想跟我谈恋爱吗
腾：所以你想跟我处兄弟吗
她：为什么要
……
她：在干嘛
腾：收拾下去看电影
她：你俩？ / 蜘蛛侠非得看 / 能单独跟我看的机会你不看
腾：就我 / 咱俩看痴迷吧
她：不看
```
→ 腾的判断：
- "看电影还真就是为了看电影"是**暗示**，她嘴硬说"不然呢"，说明她懂，只是要对抗
- 她反抛"所以你想跟我谈恋爱吗"，他原样抛回"所以你想跟我处兄弟吗"
- "能单独跟我看的机会你不看"是**带指责的推拉**：把锅扣到你身上，其实就是想跟你看
- 这类线上聊不出暧昧，**直接引线下**

**可迁移的招**
- 对抗型的不跟她聊暧昧，跟她对抗：说她"真难伺候"
- 她反问你，你用同样句式反问回去
- 带指责的话 = 她想跟你在一块

## 案例 6｜讲义案例：冷暴力后的委曲求全（腾自己的反面教材）
**来源**：腾的讲义《6年约会博主纯手写感悟下篇》，4-1 投屏 [31:54]–[32:31]，2022 年 10 月

```

（她发"讨厌我的人有福啦"表情包）
腾：我也挺担心的

腾：你态度变化那么快 / 第一反应难道不是我思考自己做错了什么吗 / 你跟你朋友之间都这样的嘛
```
→ 腾在讲义里的复盘（原文）：
> "再到后面我一样委曲求全问她到底什么情况，如同情侣要分手了，想以有什么问题直接说出来解决不就好了的思想来想回到以前甜蜜的感觉，后来才知道：**关心你在意你的人，不会以持续冷暴力让你难受，说白了就是想把你这个人给丢掉了**……原来女生喜欢你只是当时喜欢你，喜欢你这种感觉，而当时的你可能并不是有多帅并不是多有魅力，恰恰只是在当时的环境和氛围，她当时所处的低谷情绪，促成了这段情感。"

**可迁移的判断**
- 她持续冷暴力 = 她想把你丢掉了，不要委曲求全追问"我做错了什么"
- 她当初喜欢你，可能只是当时的环境、氛围和她的低谷情绪

## 案例 11｜见面当晚的流程（老实人，接案例 2）
**出处**：3-4 截图 023/024
```

腾（23:12）：大概几点到
（腾打语音：已取消）腾：不会吧
她：到了 / 在哪

她：（发定位）
她：点了 / 我太渴了 / 然后随路点了（奶茶）
腾：不用买 / 待会饱了
```
