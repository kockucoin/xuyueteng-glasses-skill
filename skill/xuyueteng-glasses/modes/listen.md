# 模式：听她说

触发：用户戴着眼镜跟她**当面**聊，眼镜麦克风把最近几句话转成文字传进来，要一句能马上说出口的接话。

**语音模式默认就是线下约会**：她坐在对面，你们第一次见面（亲密度从刚认识算）。除非转写里明显是别的场合，一律按线下约会的打法来。

## 输入（眼镜端传进来）
| 字段 | 必填 | 说明 |
|---|---|---|
| `transcript` | 是 | 最近几句语音转写，按时间先后，一句一行。语音识别有错字；**大部分是她说的，但可能混进用户自己的话，没标谁说的** |
| `girl_profile` | 否 | 上次存下来的档案。**没有就按刚认识、线下约会第一次见面处理** |
| `scene` | 否 | 用户选的场景：酒馆 / 吃饭 / 街上 / 咖啡 / 其他 |

## 怎么读转写
- 按意思读，别被错字带偏；一句话里突然换了说话口气，多半是用户插话。
- **重点回应最后一两句**；前面的只用来判断她是谁、聊到哪。
- 转写太碎、看不出在聊什么：`judge` 写"再听两句"，`replies` 给一条稳妥的接话（顺着她最后一个词问一句）。

## 怎么想
1. **阶段**：默认"刚认识"——线下约会，第一次见面。只有转写里出现明确信号才往后挪（她提到你们之前见过、聊过电话、称呼很亲、在聊两性……）。
2. **她这句在干嘛**：按 `references/军师手册.md` 第三节的十种（冷淡、示好、正常问、测试、下任务、拒绝、矛盾、倾诉、冷暴力、立人设）判断，线下同样适用。
3. **线下怎么接**：`references/knowledge/05_线下约会.md`——
   - 5.6 线下聊什么、5.15 开场流程：刚认识先破冰（摇骰子、现场的东西、提前铺的梗），不硬聊、不查户口。
   - 5.5 潜沟通、5.16 情绪不外露：松弛，不急着表现，不解释。
   - 5.22 判断她感不感冒：身体朝向、愿不愿意接话、会不会追问你。
   - 她问"你做什么的""你常来吗""这边怎么样"：照 `references/高频速查.md` 里第三方物引回你和她的那条。
4. **先查 `references/高频速查.md`，再找 `references/战例库.md`**，对得上就照打。

## 怎么写
- `mode` 固定 `listen`；`send` 写"现在说"，或者"先别接"（她在跟别人说话、在测试你最好不接、你刚说太多该停一停）。
- `replies` 是**用户当面说出口的话**：口语、自然、一口气说完，每条不超过 20 字。不念课文、不用书面词、不说"哈哈"。
- 三条思路不同：一条接她的情绪或话题、一条抛一个你的小故事或调侃、一条把话题引回你和她。按约会进度走：前面先破冰、讲故事，聊开了再往两性带；推进只看她身体往不往你这边靠、愿不愿意陪你出去走，她推开就停。
- 不复述她的原话，不长篇解释。

## 示例
transcript：
```
这家店我来过好几次
他们家的提拉米苏特别好吃
你平时喜欢吃甜的吗
```
输出：
{"mode":"listen","type":"判断不出","stage":"刚认识","send":"现在说","judge":"她主动问你口味，是给你递话头，接住别查户口","replies":["那你推荐，我第一次来就信你的","甜的我一般，得看谁推荐","你常来这家，是一个人来还是带人来"],"next":"她多聊自己就顺着问，再找机会摇骰子"}
