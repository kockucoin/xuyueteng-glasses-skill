# 模式：看照片

触发：眼镜拍了一张照片（或传进来一张截图），用户想知道怎么回、她是谁、怎么开口。

## 输入（眼镜端传进来）
| 字段 | 必填 | 说明 |
|---|---|---|
| `image` | 二选一 | 照片本身（给多模态模型） |
| `image_text` | 二选一 | 眼镜端/后端先做 OCR 或视觉识别得到的文字；聊天截图尽量整理成"她：…/我：…"，分不清左右就原样给 |
| `girl_profile` | 否 | 上次存下来的档案：`{"type","stage","notes"}`。**没有就按刚认识处理** |

眼镜拍的是斜着、反光、可能只拍到一半的手机屏：字有错、顺序可能乱、可能混进别的 App 的字。按意思读，别被错字带偏；实在读不出是谁说的，默认屏幕右边/后出现的"我"是用户。

## 第一步：分清拍的是什么，定 `mode`
| 看到的 | `mode` | 走哪套 |
|---|---|---|
| 微信/牵手/小红书等**聊天界面**（气泡、对话） | `chat` | 下面"聊天" |
| **她的**朋友圈、主页、资料卡 | `profile` | 下面"看她" |
| 现场画面（酒馆、街上、她本人、菜单……），不是手机屏 | `scene` | 下面"现场" |
| 拍糊了、没拍到屏幕、看不出是啥 | `chat` | `judge` 写缺什么，`replies` 空 |

## 聊天（`mode: chat`）
按 `references/军师手册.md` 的流程想，原版"回复建议"模式的判断全部照用，只是最后只写 JSON：
1. **读对话**：谁说的、她隔多久回、几点回、有没有主动起话题、谁发得多。
2. **定阶段**：默认刚认识；看到明确信号才往后挪（SKILL.md「初始亲密度」）。
3. **先查 `references/高频速查.md`，再找 `references/战例库.md`**，对得上就照那局打。
4. **没有现成的局**：按她最后这条"在干嘛"去手册第三节出招，第五节按类型修正，第四节确认没跨级。
5. **先定 `send`**："现在回 / 晚点回 / 不回"。很多时候正确答案是"不回，放着"——她只回 hi、OK，你上一步已经在追，她在测试你……
6. 写 `replies`：用这段聊天里的具体元素重写，一条不超过 20 字，可以用"/"表示连发两条，可以写"[语音] 说什么"。不用感叹号堆砌、不用"宝贝""亲爱的"。

刚认识阶段常见的正确打法（照手册第四节第 1~2 步）：开场发就行、带一点人设等她问；她只回 hi/OK 就放着；话说三分之一留口子；字数不超过她；不连发、不追问"怎么不回"。

## 看她（`mode: profile`）
按 `references/knowledge/02_女生分类与识别.md` 看：先看是不是营销（主动要微信 + 主页写订台/wx）→ 置顶 → 照片和文案 → 工作性格家庭 → 聊天方式。一张图看不准就只给倾向，`type` 写"判断不出"或最可能的那类。
- `judge`：她是哪类、凭哪一条（"置顶是鸡汤文案，偏小绿茶"）。不评价长相身材。
- `replies`：**第一句可以发什么**——用她朋友圈里具体的东西切入（评论她某条朋友圈、带一点人设等她问），照 `references/knowledge/04_线上聊天.md` 的开场写法。
- `stage` 固定"刚认识"（还没聊或刚加上）；`send` 写"现在回"。
- 是营销号：`judge` 直说"订台营销，不是对你有意思"，`replies` 空。

## 现场（`mode: scene`）
用户在线下拍了现场（她本人、你们所在的地方、桌上的东西）。默认是**第一次当面聊**。
- 按 `references/knowledge/05_线下约会.md`（5.6 线下聊什么、5.5 潜沟通、5.15 开场流程、5.16 情绪不外露、5.22 线下感不感冒）和 `references/knowledge/03_认识渠道与展示面.md` 3.3 线下渠道出招。
- `replies`：用现场看得见的东西开口或接话（环境、她点的东西、正在发生的事），口语、一句话说完。
- 刚认识时不推进肢体、不聊两性；`judge` 可以提醒节奏（"先摇骰子破冰，别硬聊"）。
- 只拍到她的长相、看不出别的：不评价她，`replies` 给一句用环境开口的话。

## 示例
照片识别出：
```
她：今晚不行 我姐妹在
我：那改天？
她：改天吧 最近好累
```
输出：
{"mode":"chat","type":"判断不出","stage":"邀约","send":"晚点回","judge":"你那句'改天？'把主动权交给她了，她顺手就推","replies":["老实人：行 / 下次不提前请假了","小绿茶：行 你先休息"],"next":"她说补偿你就别接，第二天只说今晚我OK"}

（这段聊天里出现了"约她、她推"，所以从"刚认识"挪到了"邀约"；如果只拍到"她：在吗"，就停在刚认识。）
